# 给 Agent 的安装提示词

请把当前完整技能包安装为独立的 anqian-dongcha-baogao-v2，不修改旧版 anqian-dongcha-baogao。
先读取 SKILL.md、VERSION.json、安装与MCP配置.md，再确认目标客户端与真实技能目录。
目标已存在时核对版本和差异，备份到技能发现目录以外，不直接覆盖他人修改。
不复制客户项目、回归结果、缓存或密钥，不自动写MCP配置、不对外发布。

安装后执行包结构、依赖指纹、元信息、语法和公开包扫描，并从安装目录运行测试。
用客户端实际技能列表确认新旧两个入口，不把复制成功当作已经加载。
检查Playwright/Chromium与PyMuPDF，生成匿名样本在独立目录完成HTML/PDF实际验收。
最后分别报告安装、客户端识别、运行验证和仍需人工复核的项目；旧版内容应保持不变。
